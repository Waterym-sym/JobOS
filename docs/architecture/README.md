## 统一约束（跨篇不可违反）

1. **Evidence → Match → Resume Claim / 招呼语陈述** 溯源链不可断；模板、JD、聊天原文均不构成证据。
2. **系统不自动投递、不自动发消息、不自动翻页、不自动上传附件**；一切对外动作由本人人工触发（ADR-009）。
3. **聊天原文仅存本机 loopback**，默认不进第三方模型上下文；自动分类只产事件草稿，人工确认才入账（ADR-006/012）。
4. **筛选只建议、不替人决策**：Stage-0 纯规则可解释可捞回；候选区必须人工确认；复盘策略建议人工审核后才生效，不自动调权（ADR-008）。
5. **模板只承载呈现、不承载事实**；ATS 与 Showcase 渠道边界不可混用；DOCX 仅开源解析，复杂版式允许降级（ADR-010/011）。
6. 系统不承诺「保证沟通/约面」；效果以漏斗指标可观测、可复盘表达。
7. 所有服务仅绑定 127.0.0.1，单用户本地部署；无多租户、无云 SaaS 组件。
8. 机器契约真源在仓库根 [`contracts/`](../../contracts/)（WS 协议/OpenAPI/DDL/DSL/Filter，v0-draft 起 P0 冻结）；契约先行，文档为语义真源。
9. AI 编程代理必须遵守仓库根 [`AGENTS.md`](../../AGENTS.md) 与[第 24 篇](24-AI协作开发规范与边界.md)：红线即禁令，越界即停。
