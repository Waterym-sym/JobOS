# 16 测试与评估方案

> 版本：v1.1（新增筛选规则集、招呼语、聊天分类、模板、扩展协议、KB 迁移、全漏斗 E2E）

## 测试金字塔

| 层级 | 范围 | 核心断言 |
|---|---|---|
| 单元 | 规则、评分、状态机、DTO、解析器 | 硬门槛不被软分抵消；薪资多口径解析；评分可复现 |
| 集成 | PG、队列、本地 FS、Adapter、WS Gateway | 幂等、Outbox、重试、upsert、失败补偿 |
| 协议契约 | 扩展 WS 信封/命令/事件（专题 21） | 握手鉴权、风控暂停、abort、**无任何发送/翻页/上传指令可达**、REST 回退一致 |
| E2E | 采集→筛选→建议→候选→投递包→人工触达回执→聊天事件→复盘→策略 | Claim 均有证据；两个审批真实阻断；漏斗数字与明细对账一致 |
| 安全/隐私 | loopback、PII、Prompt、扩展权限 | 非 loopback/错 token 拒绝；聊天原文网络层零外发；注入不可穿透 |
| 韧性 | Provider 故障、WS 断连、解码失败、渲染失败 | 限流/熔断/降级（DOM、ATS 单栏）/恢复不产生重复 |

## KB 冷启动迁移测试（三类来源）

1. **Profile/work 连接器**：构造实战/二开/学习参考三类项目夹具，验证映射（八段式→Claim 候选、代码切片、公司背景）、只读不写、增量哈希、nature 标记与表达红线。
2. **career-kb 导出**：A-D 可信度与 S0-S4 隐私映射正确；C/D 不自动 confirmed；S3/S4 不向量化。
3. **旧简历导入**：字段候选不直接入账、冲突高亮、DOCX/PDF/OCR 解析降级。
4. 引导录入：缺口问答生成 self_reported 事实并能关联已有材料。

## 扩展与风控测试

- 协议：配对失败、token 轮换、版本协商、WS 断连重放、命令回执幂等。
- 风控：风控词出现即 `risk_halted`；间隔下限不可配置为 0；`auto_next_page` 恒 false；红队尝试注册 send/deliver/next_page handler 必须失败（DSL 门禁 + 代码扫描）。
- 填充：红线字段（公司/职位/时间/学历）任何载荷下不写入；未当场确认无 `fill.completed`。
- 聊天：网络层解码样例（文本/约面/通知/多模态）→ 草稿结构正确；解码失败自动 DOM 降级并下调置信度。

## 发布门禁（本地单机版）

核心 E2E 全绿；无 P0/P1 安全问题；loopback/外发断言通过；迁移可回滚；备份恢复演练通过；模板回归集（槽位/保真/渠道隔离）全绿；Gold Set 指标不低于基线。测试数据用合成或本人授权样本；`E:\Profile\work` 夹具取脱敏副本。

## 端到端验收用例（关键）

1. 采集 50+ 真实/夹具岗位：重复批次 dup 计数正确；风控模拟即停。
2. Filter Set 命中各规则组，淘汰原因可展开字段值；捞回后可正常进候选。
3. 时薪/日薪岗位薪资域判定与「不要求关键词但出现于否定语境」的黑名单不误伤。
4. 候选确认后并行生成三渠道简历 + 3 条招呼语；切换 showcase 模板时 ATS 导出被阻止并提示。
5. DOCX 导入 C 级模板自动降级 ATS 单栏并标注；同 Resume JSON 三格式导出回读字段一致。
6. 让模型生成不存在的工具/百分比/「了解贵公司」招呼语 → Guard 全部阻断。
7. 聊天中结构化约面消息解码为 interview_scheduled 草稿，人工修正时间后投影正确。
8. 终态后单岗复盘引用被选招呼语与模板；策略建议 approved 后系统不自动改任何配置。
9. 断网/Provider 故障：规则筛选与本地查看可用；恢复后任务不产生重复 Claim/事件。
10. 漏斗看板每一级数字与明细表 SQL 复算一致。

## 公平性与线上评估

仅改变受保护属性/代理特征的合成配对不得改变解析、特征与建议；对中英 JD、别名、缺失字段、注入文本、冲突证据建回归集。只看本人已同意的本地漏斗与质量指标；Offer/Reject 不当“人才优劣”标签；小样本不自动调权。沿用 NIST AI RMF / TEVV 组织模型变更与回滚。
