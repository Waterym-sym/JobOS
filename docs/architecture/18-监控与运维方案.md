# 18 监控与运维方案

> 版本：v1.1（本地健康检查 + 求职漏斗仪表盘 + 扩展状态；Runbook 覆盖风控/解码/渲染/导入）

## 可观测性（本机轻量栈）

全链路 `trace_id`（控制台 → API → Worker → 模型/渲染）；日志写本地文件（按日滚动），只记资源 ID、哈希、脱敏摘要、错误码，不记 Token、完整简历、聊天原文与原始 Prompt。控制台内置「运行记录」可按 trace 查看。

## 求职漏斗仪表盘（核心新增）

| 区块 | 指标 |
|---|---|
| 漏斗 | captured → screened_pass → shortlisted → greeted → replied → interview_scheduled → offered 各级数量、转化率（去重口径与 08 篇一致）、时间窗口筛选 |
| 筛选 | 各 Filter Set 版本通过/淘汰数；淘汰按 `rule_id` 分布；捞回数及捞回后下游转化 |
| 采集 | 批次成功/重复/风控暂停、平均节流耗时、待补详情数、扩展连接状态与协议版本 |
| 触达 | 招呼语分变体：发送数、回复数、回复率（A/B）；模板使用次数与导出成功率 |
| 复盘 | 待复盘终态岗位数；拒绝原因分布（沟通拒绝/面试拒绝/已读不回）；策略建议 proposed/approved/applied 计数 |
| 系统 | 任务队列深度/失败、token 与成本（按域）、存储水位、备份状态 |

数字必须可下钻到明细表并与 SQL 复算一致；不做“提高沟通率”的因果宣称，只呈现观测。

## 技术指标

| 域 | 指标 | 本地告警方式 |
|---|---|---|
| API/WS | 成功率、P95、5xx、配对失败、WS 断连率 | 控制台状态红点 + 通知 |
| Worker | 队列深度、失败/重试、死信、渲染失败率、**DOCX 导入失败率** | 任务页标红 |
| AI | token、成本、schema 失败、Guard 拦截分类 | 超预算提醒 |
| 模板 | 渲染失败率、回读不一致、降级（C 级/ATS 重建）次数 | 失败定位到模板/槽位 |
| 扩展 | 连接、协议版本、风控暂停、解码来源分布（network/dom） | 风控即弹窗 |
| 隐私 | 第三方请求中 restricted 数据命中（应为 0） | 命中即 P0 告警并阻断 |

SLI 参考：本机 CRUD P95 ≤ 300ms；ATS 模板解析成功率 ≥ 98%；Workflow 完成率 ≥ 99%（用户取消与审批超时单列）。错误预算用于暂停非必要新功能。

## Runbook

1. **登录失效 / 风控暂停**：扩展检测到跳登录或风控词 → 批次 `risk_halted`；处理：停止当天采集、人工检查账号状态、恢复后从断点继续；不绕过验证码。
2. **WS 断连**：自动指数重连；未确认事件本地缓存重放；长时间断连时控制台提示「回退 REST」；检查 8788 端口与配对 token。
3. **页面结构/接口变更**：采集字段缺失率升高或选择器报错 → 该批次部分失败、进入「待补采」；更新扩展，协议契约测试先行。
4. **聊天解码失败**：网络层解码错误（proto 不匹配）自动降级 DOM，`decode_source=dom`、置信下调、事件必须人工确认；连续失败提示升级扩展。
5. **Provider 不可用/成本异常**：熔断、规则与本地查看不受影响；任务保留待重跑；超预算节点不静默执行。
6. **模板渲染失败**：按定位（模块/槽位/字体/分页）处理；DOCX 复杂版式启用 ATS 单栏降级并告知；Chromium 崩溃自动重启 renderer。
7. **DOCX 批量导入失败**：失败报告（损坏/加密/槽位全 unknown），断点续跑；许可证缺失模板整批拒绝。
8. **备份与恢复**：使用一键导出/恢复；大版本前演练 pg_dump 恢复；恢复后校验漏斗投影与事件重建。
9. **数据删除/聊天清除**：按会话清除 chat_message 与原始加密包并撤销相关文件；复盘报告保留脱敏引用。

## 审计与响应

本地审计日志记录：配对/轮换、采集批次、筛选运行、候选确认、导出、填充、发送回执、事件确认、策略审核、模板导入与许可。P0（聊天外发/绕过 Guard/数据损坏）立即停服排查；P1（核心链路持续失败、风控误停未恢复）当日处理；P2 随版本修复。P0/P1 做无责复盘。每周看漏斗质量与成本，每月做恢复演练与 Gold Set 漂移检查。
