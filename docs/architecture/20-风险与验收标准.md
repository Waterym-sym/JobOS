> 版本：v1.1（新增 BOSS 风控/插件变更/聊天隐私/模板版权与版式风险；全漏斗验收）

> 2026-09-18 多用户目标补充见文末「ADR-013 附加风险与人审门」。本篇既有 P0–P6 阈值、自动外发/聊天隐私 No-Go 未被降低；现有单机验收口径不等于公网发布许可。

## 验收标准

| 类别 | 门槛 |
|---|---|
| 全链路功能 | 真实本机样本跑通 采集→筛选→建议→候选→投递包（三形态+招呼语）→人工发送→回采→复盘→策略审核；候选区为唯一投递入口 |
| 筛选可解释 | 每条淘汰可定位规则+字段值；可捞回；筛选零 LLM 调用；漏斗各级与明细对账一致 |
| 真实性 | 已使用简历/招呼语 unsupported Claim = 0；不支持/矛盾/虚构了解/承诺 100% 阻断；学习项目冒充在职 100% 拦截 |
| 模板 | ATS 模板解析成功率 ≥98%、关键字段完整 ≥95%；槽位映射 100%；DOCX 导入开源引擎、失败有报告、降级显式告知；三格式字段一致 |
| 渠道隔离 | showcase 不能无提示进入 ATS；在线载荷红线字段零写入 |
| 自动化红线 | 代码/协议/DSL 三层不存在自动发送/投递/翻页/上传路径（静态扫描+红队测试） |
| 聊天 | 原文仅本机（外发断言为 0）；事件草稿必须人工确认；约面/拒绝分类 ≥0.90；解码失败可 DOM 降级 |
| AI | Requirement F1 ≥.80；Evidence Recall@10 ≥85%；Claim Support Precision ≥95%；招呼语溯源 100% |
| 安全 | 非 loopback/错 token 100% 拒绝；无 P0/P1；配对/采集/确认/导出/审核全审计 |
| 运维 | 备份恢复演练通过；Runbook 覆盖风控/断连/接口变更/解码/渲染/导入；存储水位可见 |

## 验收证据包

每项附：文档/协议版本、E2E 报告或录屏（真实采集样本）、Gold Set 原始结果（含规则边界集/招呼语/聊天分类/模板回归）、WS 协议契约测试、loopback 与外发网络断言、无发送路径扫描报告、DOCX 导入报告样本、备份恢复记录、已知限制。UAT 样本覆盖：不同薪资口径、活跃度分档、猎头/好友岗、否定语境关键词、证据充分/不足/冲突、ats_direct_post 与否、中英 JD、A/B/C 级模板、结构化约面与普通寒暄消息。

## Go / No-Go

**Go**：P0–P6 门禁全达；P0/P1 风险项为零；真实账号小批量（人工节奏）验证采集与回采稳定；备份/清除可用。
**No-Go**：存在任何自动外发路径、可绕过 Truth Guard、聊天原文可出本机、Showcase 可静默进 ATS、商业库进默认栈、漏斗数字无法对账。
效果复验：上线后第 7/30/90 天看漏斗各级转化与拒绝原因分布（观测，不作结果承诺）、Guard 拦截、模板导出失败、成本与账号安全状态；Outcome 学习仅在样本量与偏差审查通过后，以「人工审核的建议」形式参与。

## ADR-013 附加风险与人审门（proposed）

| 新风险 | 控制与需留存的证据 |
|---|---|
| 跨账号数据泄露、越权操作 | 服务端身份确定 owner；所有个人行/文件/缓存/后台任务列入归属清单；两求职者、招聘者、管理员矩阵验证跨账号读写零成功，含直接对象 ID 与连接复用 |
| 公网入口暴露扩展令牌或内部服务 | Web 会话与扩展配对令牌分离；内部 API/WS、PostgreSQL、Redis、Worker、管理接口无公网监听；公网模式禁采集；网络与代理配置审计 |
| 账号接管、伪造注册与重置 | 管理员邀请、服务器端首管引导、密码哈希、服务端会话、Cookie/CSRF/Origin、限流、一次性重置和会话撤销；负例与审计报告 |
| 上传文件越权、恶意文件或错误解析承诺 | 仅 PDF/DOCX，大小与内容校验、私有路径、跨账号下载拒绝；原件保存和解析状态分开，不导入示例个人信息 |
| 旧数据误归属、降级合并或注销残留 | 备份、首管归属对账、隔离库 upgrade/downgrade；不兼容降级拒绝；注销删除与会话/缓存/文件清理对账，最后管理员先移交 |

**实施门**：ADR-013 与权限/数据归属方案先由独立人审；未通过不得改认证、DDL 或 UI 业务代码。**公网发布门**：本地功能测试通过后另行审查 TLS、网络隔离、恢复、滥用防护和隐私；未审不得实际对公网开放。既有自动外发、聊天本机、Truth Guard 和 P0/P1 风险项 No-Go 原样适用。
