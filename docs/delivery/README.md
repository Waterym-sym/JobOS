## 三条不可协商的组织原则

1. **红线评审不能交给 AI，也不能作者自审**：自动外发、聊天隐私、真实性 Claim、账号风控四类变更必须由「另一个人」或本人以独立评审单过闸（单人开发时用 24 小时冷却 + 清单复核 + 自动化负向测试三重替代）。
2. **阶段出口用真实数据演示**，不用 mock 录屏收尾（见 [19](../architecture/19-项目实施计划.md)、[20](../architecture/20-风险与验收标准.md)）。
3. **先小后大**：任何阶段都先用本人账号的小批量真实样本（采集数十条、投递个位数）跑通再放量；账号安全优先级永远高于进度。
