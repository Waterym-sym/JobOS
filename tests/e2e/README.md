# End-to-end tests

Browser E2E coverage is still pending. Pairing, gateway, capture, and pool-screening
tests currently cover API and extension behavior, but they do not establish a
browser end-to-end or real-sample stage exit. Future E2E tests must use synthetic
pages and never a real recruitment account for automation. See
[the project status snapshot](../../docs/delivery/06-项目状态快照.md).
